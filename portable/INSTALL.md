# Local Chinese TTS macOS 安装包

## 适用设备

- Apple Silicon Mac（M1、M2、M3、M4 或更新）
- macOS 15 或更新版本
- 至少 8GB 内存；高质量档在 8GB 设备上按需使用
- 建议预留 10GB 可用磁盘

## 安装

1. 解压 `LocalChineseTTS-Portable-macos-arm64.zip`。
2. 双击解压目录内的 `install.command`。
3. 首次若系统提示，请右键选择“打开”。
4. 安装完成后访问 `http://127.0.0.1:8765/`。

如随包附有 `.zip.sha256` 文件，可在终端执行 `LC_ALL=C shasum -a 256 -c 文件名.zip.sha256` 验证拷贝是否完整。

安装器会把本体部署到 `~/.local-chinese-tts`，把 Codex 技能部署到 `~/.codex/skills/local-chinese-tts`，并注册登录启动项与“中文音色朗读”macOS 服务。

这是 macOS 专用便携安装包。项目核心 HTTP 服务可在 Linux 上部分使用，但该安装包不支持 Linux 或 Windows。

## 模型与默认值

- `K01` 是默认的完全离线轻量女声，适合日常朗读和选中文字服务。
- `K01`–`K04` 是轻量离线模型。
- `QF1`–`QF10`、`QM1`–`QM3` 是高质量离线模型；其中 QF3–QF10 为甜美、小女孩可爱、纯真、元气、俏皮、软萌、清甜、情感等女声预设。8GB Mac 上单次合成约需 5GB 峰值内存，适合按需使用。
- `F01`–`F10`、`M01`–`M03` 是在线备用音色，仅在明确选中时使用。

模型已包含在安装包中。本机模型在合成时强制离线，不会下载或上传朗读文本。

动态朗读缓存会保留 3 天，后台任务每天凌晨 03:15 清理。它只处理 `cache/`，不会删除模型、设置或手动导出的文件。

## 兼容性说明

安装包包含当前 Mac 的 Python 虚拟环境，若目标机也安装了 Homebrew Python 3.12，通常可直接离线运行。若虚拟环境不兼容，安装器会保留旧环境并使用目标机的 Python 3.10+ 重建；这一步需要联网下载 `requirements.txt` 中的依赖，但本地模型无需重新下载。

## 日常使用

- 控制面板：`http://127.0.0.1:8765/`
- 选中文字：App 菜单“服务”→“中文音色朗读”
- API：`http://127.0.0.1:8765/v1/audio/speech`
- 全局技能：`$local-chinese-tts`

在控制面板选择音色会同步更新“中文音色朗读”服务的默认声音。
